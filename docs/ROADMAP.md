# 饮食软件产品 Roadmap

## 1. 产品发展路径

饮食记录工具
→ 完整饮食管理 App
→ 多功能个人记录平台
→ 离线与 App 产品化
→ AI 个人助手

## 2. 整体阶段

### Phase 0：底层架构与开发规范

Phase 0不作为独立产品版本，而是贯穿整个项目。

主要要求：

- 统一数据访问层
- 页面与Supabase调用逐步分离
- 公共数据与私人数据分离
- 管理员与普通用户权限分离
- 数据库迁移管理
- 计划数据与实际记录数据分离
- 历史营养数据快照
- Git提交和版本记录
- 更新日志和测试记录
- 数据导出、备份和恢复基础
- 为本地数据库、离线同步和多端同步预留接口
- 开发环境和正式环境逐步分离

核心原则：

> Phase 3才正式开发离线功能，但Phase 1的数据访问层和数据结构必须提前考虑未来离线与同步。

### Phase 1：完整饮食管理 App

Phase 1是当前主要开发阶段，需要有详细版本、功能范围和完成标准。

包含：

1. 账号与权限
2. 食物数据库
3. 饮食记录
4. 历史记录与统计
5. 身体记录
6. 饮食计划
7. 模板
8. 周饮食计划
9. 规则驱动自动生成
10. 独立减脂模式
11. 稳定化与正式上线

### Phase 2：多功能个人记录平台

目前只保留总体框架，不拆分详细版本：

- 训练记录与训练计划
- 日程、任务和时间管理
- 记账与预算
- 多模块统一时间轴
- 统一搜索和标签
- 多模块统计
- 饮食、训练、日程和记账之间的数据关联

目标版本：

```
V2.0 多功能个人记录平台
```

### Phase 3：离线与 App 产品化

目前只保留总体框架：

- 本地数据库
- 离线查看和记录
- 云端同步
- 待同步队列
- 多设备冲突处理
- 备份和恢复
- PWA安装
- App封装
- 推送通知
- 多端稳定使用

目标版本：

```
V3.0 离线与 App 产品化
```

### Phase 4：个人助手

目前只保留总体框架：

- 跨模块统计与总结
- 自动化规则
- AI查询个人数据
- AI解释数据变化
- AI生成计划草稿
- 用户授权后执行操作
- 新闻订阅与总结
- 个人知识库
- 文件、网页和笔记问答

目标版本：

```
V4.0 个人助手
```

## 3. Phase 1详细版本

### V0.1：账号、权限与真实数据底层

目标：

保证用户可以稳定登录，并安全使用真实数据库。

范围：

- Supabase环境配置
- 用户名和密码登录
- 登录、退出和会话恢复
- profiles用户资料
- 管理员身份
- 普通用户身份
- 公共和私人数据权限
- RLS策略
- 清理Mock和演示数据
- 新用户真实空状态
- 数据库迁移文件
- 基础错误处理
- 本地与线上构建测试

完成标准：

- 用户名登录在线上正常工作
- 刷新后保持登录
- 退出后清除上一个用户的数据状态
- 不同用户无法查看彼此私人数据
- 管理员权限正确
- 新用户没有演示数据
- Supabase真实数据链路稳定
- 本地和线上构建通过

### V0.1.3：基础记录闭环与稳定性收尾

目标：

在不扩展新业务模块的前提下，完成 v0.1 阶段核心记录链路的验收闭环、缺口修复与稳定性收尾。

纳入范围：

- 登录、退出和账号切换链路收尾。
- 首页饮食记录新增、编辑、删除链路收尾。
- 删除全部食物后自动删除空餐规则收尾。
- 结束本日、下一记录日推进与首页日期规则一致性收尾。
- 删除本日历史后首页回到真实本日规则收尾。
- 历史记录查看、编辑、单条删除与批量删除收尾。
- 设置入口进入历史记录与底部导航三入口收尾。
- 食物库基础能力与用户数据权限收尾。
- 基础摄入计划功能收尾。
- 刷新、重新登录后的状态一致性收尾。
- 手机端主要页面验收收尾。
- Production 版本与部署一致性核验收尾。

明确不纳入：

- 统计模块增强。
- 模板功能。
- AI 功能。
- 离线数据库与同步体系。
- 图片体系扩展。
- GI/GL 扩展字段。
- 健身模块独立扩展。
- 记账模块。

完成标准：

- 核心链路全部具备代码证据、测试证据和可复验检查记录。
- 高风险路径（日期规则、删除、切换账号）完成回归用例覆盖。
- 版本文档、状态文档、版本索引与发布记录保持一致。
- 仅在正式生产验证完成后填写上线时间与发布回填信息。

### V0.2：食物数据库

目标：

建立可长期维护的真实食品数据库。

范围：

- 食品新增、修改、删除或停用
- 食品搜索和筛选
- 公共食品
- 私人食品
- 管理员维护公共食品
- 普通用户维护私人食品
- 名称、品牌和备注
- 每100克热量
- 蛋白质、脂肪和碳水
- 默认份量和单位
- 数据来源
- 图片引用
- 重复食品提醒
- 常用食品
- 最近使用食品

后续可扩展字段：

- GI和GL
- 快碳和慢碳分类
- 膳食纤维
- 糖
- 钠
- 条形码
- 生熟状态
- 数据可信度

完成标准：

- 普通用户可以新增私人食品
- 普通用户不能修改公共食品
- 管理员可以修改公共食品
- 所有食品操作均写入真实数据库
- 页面刷新后数据不丢失
- 不同用户之间私人食品隔离正确

### V0.3：完整饮食记录

目标：

用户能够完整记录每日饮食。

范围：

- 早餐、午餐和晚餐
- 多次加餐
- 一餐包含多个食品
- 食品克重
- 热量和宏量营养自动计算
- 修改和删除食品
- 修改和删除餐次
- 修改记录时间
- 每餐汇总
- 每日汇总
- 日期切换
- 历史记录
- 营养数据快照
- 常用和最近食品入口

完成标准：

- 所有记录写入真实数据库
- 页面刷新后记录不丢失
- 修改和删除正确
- 重复提交不会产生重复数据
- 食品库后续修改不会改变历史记录
- Today和History数据一致
- 手机端可以顺畅完成记录

完成V0.3后发布：

```
V0.3 Alpha：个人饮食记录可用版
```

### V0.4：历史记录与基础统计

范围：

- 每日历史记录
- 每周平均摄入
- 每月平均摄入
- 热量趋势
- 蛋白质、脂肪和碳水趋势
- 每餐摄入占比
- 常吃食品
- 达标天数
- 目标与实际差距
- 修改记录后自动重新统计

完成标准：

- 日、周、月统计口径一致
- 图表与原始记录一致
- 空数据时不会产生错误结果
- 跨日期统计正确
- 页面加载稳定

### V0.5：身体记录

身体记录是独立、长期存在的功能，不依赖减脂模式。

范围：

- 体重
- 腰围
- 胸围
- 臀围
- 大腿围
- 手臂围
- 体脂率
- 测量日期和时间
- 测量状态
- 备注
- 长期历史记录
- 体重趋势
- 围度趋势
- 7日平均体重
- 周平均变化
- 任意日期对比
- 身体数据与饮食数据对比
- 对比照片作为后续可选功能

完成标准：

- 可以长期新增和修改身体数据
- 可以选择任意两个日期对比
- 可以查看平均体重而不是只看单日数据
- 身体记录独立于减脂周期
- 删除减脂周期不会删除身体记录

### V0.6：饮食计划

范围：

- 热量目标
- 蛋白质目标
- 脂肪目标
- 碳水目标
- 四项填三算一
- 计划生效日期
- 历史计划保存
- 训练日和休息日计划
- 每餐目标分配
- 实际与目标比较
- 当天剩余热量和营养显示

完成标准：

- 四项填三算一正确
- 不产生负数或冲突结果
- 新计划不会修改过去计划
- 不同日期匹配正确计划
- 记录页面显示当天剩余目标

完成V0.6后发布：

```
V0.6 Beta：饮食管理测试版
```

### V0.7：模板与快速复用

范围：

- 单餐模板
- 一日模板
- 常用食物组合
- 从历史记录创建模板
- 应用模板
- 复制上一餐
- 复制昨天
- 应用模板后独立修改
- 手动更新模板

完成标准：

- 模板与实际记录相互独立
- 删除模板不会影响历史记录
- 停用食品有提示
- 用户可以明显减少重复录入操作

### V0.8：周饮食计划

范围：

- 周视图
- 每天各餐安排
- 复制某一天
- 复制上周
- 应用模板
- 每日计划营养汇总
- 全周营养平均值
- 计划转为实际记录
- 计划与实际比较
- 已完成、部分完成和未执行状态

完成标准：

- 可以建立完整一周计划
- 计划和实际记录不会互相覆盖
- 可以局部修改某一天或某餐
- 可以复制上周后调整
- 可以查看计划执行情况

### V0.9：规则驱动自动生成

第一版不得依赖AI进行核心营养计算。

范围：

- 根据热量和宏量目标生成
- 根据餐次数量生成
- 根据用户食品库生成
- 排除不喜欢或不能吃的食品
- 控制每餐热量范围
- 锁定日期、餐次和食品
- 单餐重新生成
- 替换单个食品
- 显示无法生成的原因
- 结果先保存为草稿

完成标准：

- 生成结果基本满足营养约束
- 不覆盖用户手动内容
- 所有结果都可以修改
- 支持锁定部分内容后重新生成
- 核心计算不依赖AI回答

### V0.10：独立减脂模式

减脂模式是独立目标周期，但可以调用身体记录、饮食记录、统计和计划。

范围：

- 创建减脂周期
- 开始和预计结束日期
- 起始体重和围度
- 目标体重和围度
- 热量和宏量目标
- 训练日和休息日安排
- 每周执行率
- 每周平均体重变化
- 围度变化
- 计划与实际摄入比较
- 每周复盘
- 调整历史
- 暂停、恢复和结束
- 历史减脂周期
- 多个周期对比
- 周期总结

完成标准：

- 减脂模式可以独立开启和关闭
- 身体记录在减脂模式外继续存在
- 可以区分计划没有执行和执行后效果不足
- 不根据单日体重频繁调整计划
- 所有目标和调整保留历史
- 结束后生成周期总结
- 可以对比不同减脂周期

完成V0.10后发布：

```
V0.10 Beta 2：Phase 1完整功能测试版
```
