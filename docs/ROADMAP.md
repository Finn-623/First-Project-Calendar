# 饮食软件产品 Roadmap

## 1. 产品发展路径

v0.2：v1.0 正式发布准备阶段
→ v1.0：第一套可长期使用的正式版本
→ v1.x：记录效率与用户体验优化
→ v2.0：多 Mode 生活记录平台
→ v3.0：离线优先与 App 化
→ v4.0：AI 个人助手
→ v5.0：个人知识数据库

## 2. 版本关系与发布策略

- 当前处于 `v0.2` 开发阶段。
- `v0.2` 是正式发布 `v1.0` 前的最后一个完整开发阶段。

### 发布策略

- **当前正式发布版本：v0.2.1.1**。紧急更新仅增加个人食品 kcal/kJ 输入与转换，内部继续保存kcal。
- **下一个小版本：v0.2.2**。
- **后续版本**：处理 P3。

### v0.2 开发原则

- v0.2 全部完成并通过上线验收后，软件正式发布为 `v1.0`。
- 本 Roadmap 列出的全部 v0.2 功能，都必须在 v1.0 发布前完成。
