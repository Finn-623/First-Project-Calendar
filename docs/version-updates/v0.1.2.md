## 版本概述

v0.1.2 汇总 v0.1.1 基准后的全部已完成修改，集中完善历史记录管理、实时记录、设置与账户、版本反馈、摄入计划和记录设置，并修复历史整日删除、日期状态、移动端表单和版本展示问题。

## 新增

- 历史详情默认查看/编辑双模式，支持记录编辑删除、整日删除和多日期批量删除。
- 事件与训练支持实时开始、结束、刷新恢复和首页当前时间标记。
- 设置模块新增账户管理、个人身体信息、版本反馈任务和记录设置。
- 摄入计划支持三填一算、历史快照、原子保存和历史删除。
- 新增自动归档用户设置、归档日志和 Edge Function 源码。
- 加餐时间/类型、无氧训练部位多选等记录能力。

## 优化

- 首页周日历、营养摘要和时间轴布局。
- 事件、训练创建编辑和结束本日的响应速度。
- 摄入计划移动端布局及记录设置加载稳定性。
- 登录流程的重复请求和等待体验。

## 修复

- 默认查看模式下整日删除无响应。
- 删除本日历史后停留在下一日、旧日期或旧缓存。
- 历史删除错误导航、空餐残留和刷新状态问题。
- 训练输入、备注映射、移动端弹窗与登录输入缩放问题。
- 密码提示、effect 依赖及版本页重复 `v` 问题。

## 调整与删除

- 历史记录入口改由“设置 → 记录 → 记录历史记录”直达，历史页面与路由完整保留。
- 底部导航删除历史入口，只保留首页、食物库、设置。
- 摄入计划历史取消编辑，仅保留查看和删除。
- 移除首页右上角加号、训练预估消耗和登录页测试／开发提示。
