# v0.2.1

## 发布范围

v0.2.1 包含已完成的 P0、已完成开发的 P1，以及普通事件“结束事件”功能，目标是发布稳定、可实际使用的版本。

主要范围包括：

- 公共食品导入、审核、浏览、搜索、筛选和营养详情。
- 公共食品与个人食品区分、复制、份量、停用、恢复及安全删除。
- 食品记录新增、删除、刷新、重新登录和多端同步稳定性。
- 修改意见编号、优先级、pending/completed 分页和管理员管理。
- 移动端反馈输入、新会话首页、食物库标题、未来餐次状态和结束事件。
