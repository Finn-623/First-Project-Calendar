# v0.1.3

## 版本名称

v0.1.3 — 基础记录闭环与稳定性收尾

## 版本状态

development（范围确认与任务清单建立中）

## 上线时间

待正式上线确认（status=development，releasedAt=null）

## 版本目标

- 完成 v0.1 阶段核心记录链路的最终收尾。
- 以修复缺口和补齐验证为主，不扩展新模块。

## 纳入范围

- 登录、退出和账号切换。
- 首页饮食记录新增、编辑、删除。
- 删除全部食物后自动删除空餐。
- 结束本日和自动进入下一记录日。
- 首页真实日期、当前记录日和已结束状态规则。
- 删除本日历史记录后首页返回真实本日。
- 历史记录查看、编辑、单条删除和批量删除。
- 设置入口进入历史记录。
- 底部导航只保留首页、食物库、设置。
- 食物库基础功能和用户数据权限。
- 基础计划功能。
- 刷新、重新登录后的数据与页面状态。
- 手机端主要页面。
- Production 是否为最新部署版本。

## 明确不纳入

- 统计功能扩展。
- 模板。
- AI。
- 离线数据库。
- 图片体系扩展。
- GI/GL 扩展。
- 健身模块扩展。
- 记账模块。

## 当前完成情况（代码与测试证据核对）

### 已完成，可直接验收

- 登录、退出、会话恢复主链路已实现。
- 首页当日食物删除与空餐自动清理已实现；删除成功后会立即更新餐次及当日热量、蛋白质、脂肪和碳水汇总。
- 结束本日推进与首页日期动态规则已实现。
- 删除本日历史后首页回到真实本日已实现。
- 历史记录查看、编辑、单条删除、批量删除已实现。
- 设置入口进入历史记录已实现。
- 底部导航三入口已实现。
- 食物库基础能力与权限主链路已实现。
- 基础计划功能已实现。

### 已实现但需要修复或补充测试

- 账号切换：Store 已实现 `switchAccount`，但缺少用户可见入口和回归测试。
- 刷新与重新登录状态一致性：有初始化逻辑和部分回归测试，缺少端到端验证。
- 手机端主要页面：已有适配样式与修复记录，缺少系统化验收证据。
- Production 最新部署版本：本地文档显示 v0.1.2 已上线，v0.1.3 上线前仍需执行线上版本一致性核对。

### 尚未实现，需要纳入 v0.1.3

- 账号切换入口、跳转提示与完整流程闭环。
- 核心链路端到端回归用例与发布前检查清单。

### 不属于 v0.1.3，移入后续版本

- 统计增强。
- 模板。
- AI。
- 离线数据库与同步。
- 图片体系扩展。
- GI/GL 扩展。
- 健身模块扩展。
- 记账模块。
