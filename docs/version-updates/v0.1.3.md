# v0.1.3

## 版本名称

v0.1.3 — 基础记录闭环与稳定性收尾

## 版本状态

development（范围确认与任务清单建立中）

## 上线时间

## 版本目标

- 完成 v0.1 阶段核心记录链路的最终收尾。
- 以修复缺口和补齐验证为主，不扩展新模块。

## 纳入范围

- 登录与退出账号。
- 首页饮食记录新增、编辑、删除。
- 删除全部食物后自动删除空餐。
- 结束本日和自动进入下一记录日。
- 首页真实日期、当前记录日和已结束状态规则。
- 删除本日历史记录后首页返回真实本日。
- 历史记录查看、编辑、单条删除和批量删除。
- 设置入口进入历史记录。
- 底部导航只保留首页、食物库、设置。
- 食物库基础功能和用户数据权限。
- 基础计划功能。
- 刷新、重新登录后的数据与页面状态。
- 手机端主要页面。
- Production 是否为最新部署版本。

- 验收 viewport：320×568、375×667、390×844、430×932。
- 验收方式：固定 viewport 的组件渲染与交互回归、现有页面测试、响应式结构与公共样式审查、生产构建；未连接生产数据库，未冒充真实设备人工测试。

- 首页：已修复后通过。日期、营养卡片和时间轴保留底部空间；长食物名称可换行，删除按钮扩大为 40×40px 并保持可点击；删除确认操作完整。

- 历史记录列表：通过。日期、批量删除入口和空状态结构正常，页面使用 `pb-32` 避免底部导航覆盖。
- 历史详情：已修复后通过。查看、编辑、删除入口可操作；长内容沿用时间轴换行规则；公共确认弹窗具备动态最大高度与内部滚动。
