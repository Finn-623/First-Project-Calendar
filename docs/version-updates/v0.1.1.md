## 版本概述
当前版本聚焦设置模块、账户安全和个人信息能力的持续迭代，并完善版本信息展示结构与建议任务追踪基础能力。

- 版本信息页升级为“当前版本 / 版本更新记录 / 修改意见任务”三段结构。
- 新增“提交版本修改意见”独立页面，支持提交表单、建议历史和任务状态展示。

## 功能调整
