## 版本概述
v0.1.1 已形成真实账号、真实数据库和核心记录流程的闭环基础。该版本覆盖登录认证、首页记录、历史管理、食物库、设置模块与版本建议任务能力，并在同一版本内持续完成交互修复与性能优化。

## 本版本重点
- 完成 Supabase 账号登录、会话恢复和退出清理链路（`8f9b0e8`、`bf7cde9`、`56a30f3`、`50fd18c`）。
- 完成首页与历史页核心记录流并支持整日删除、批量删除（`8026e90`、`51fe123`）。
- 完成设置模块重构与账户安全能力（`34ddd64`、`693f3f8`、`1409c82`、`176c4de`）。
- 完成个人身体信息编辑能力（`0862f84`）。
- 完成版本信息与修改意见任务模块（`af41edb`）。
